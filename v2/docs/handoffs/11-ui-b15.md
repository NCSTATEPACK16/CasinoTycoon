## Why

The user, playing the live build: "everything is on top of each other." In their screenshot at ~2000 px wide, the Opening Night card covers the build menu; the Map/Mood/Traffic toggles and the News button sit on top of the Zone list; "Walls" is clipped under the bottom bar; the Inspector overlaps the palette; the two "Today" chips run under the top bar. ## What the user decided (2026-11-05)

- **Scope:** layout **and** information presentation. Same economy.
- **Ownership:** for v2.1 **Track B owns all DOM UI**, including Track A's `Settings.ts`, `TablePlay.ts`, `src/ui/play/**`, `tools.css`, `CursorTag.ts`, `InteractPrompt.ts`. Restyle and re-house Track A's panels; don't change their behaviour. Track A keeps rendering, input logic and WebGL labels/icons, and sends UI needs as requests.
- **CSS:** the append-only rule for `ui.css` is lifted for B15. Rewrite around tokens.
- **Mockup first:** B15 step 1 builds a clickable mockup and **stops for the user to pick a variant.**
- **Screens:** 1280×720 up to 2560 wide; UI scale 80–125%; phones get a "best on desktop" notice, not a phone layout.
- **Order:** B15, then B6. B6 no longer waits for Track A's decor art (see 8-decor-b6.md).

## The target layout (what the user agreed)

- **Top bar** (one slim row): money, date and time, speed controls, rating, guests, and the scenario goal summary. These are **glanceable gauges**, each clickable: money → Finances, rating → Rating, guests → Guests. The "Today" event chips fold into **one news line** with a count; clicking opens the history.
- **Bottom dock** (Cities: Skylines): category icons — Build (floor, walls, doors, bulldoze), Zone, Slots, Tables, Services, Decor — each opening a **tray of item cards** above the dock (icon, name, price, key stat, lock badge and unlock hint). A **Manage** group on the dock opens Finances, Staff, Rating, Guests, Club, Prices and Events.
- **Windows** (RollerCoaster Tycoon): clicking a machine, table, service or guest opens a floating window with tabs (overview, stats with a small graph, settings), which the player can **drag, pin and close**; several can be open at once. The seven Manage panels are windows too. **The side panel goes away.** Windows never cover the dock or the top bar; new ones cascade; they remember their position for the session.
- **Info views:** a small icon strip — Mood, Traffic, and Appeal (new, from B6) — that recolours the floor with a legend. Hotkeys stay (M, T).
- **Goals and tutorial:** a compact, collapsible checklist at the top right, under the top bar. Tutorial step text lives there, not in a big card over the build tools.
- **Transient UI:** toasts, the tool hint, the cursor tag and interact prompt all live in named regions of one layout shell, so nothing overlaps by accident.
- **Settings:** a window (graphics High/Low from Track A's A8 when it lands, UI scale 80–125%, the four volumes).
- **Table play** (avatar view): re-housed so it no longer covers the wheel at 1280×800 (5-alive.md:412).
